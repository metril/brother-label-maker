# Bootstrap Icons curated id list (backend/scripts/symbols_pipeline)
#
# Source: bootstrap-icons@1.13.1 (npm), icons/<id>-fill.svg, native viewBox
# "0 0 16 16" (-> this project's 24x24 square via transform="scale(1.5)",
# same recipe as every other source's coordinate normalization -- see
# LICENSES.md's "Bootstrap Icons" section and fetch_bootstrap.py). FULL SET
# (unlike Material/Phosphor's hand-trimmed subsets -- same "exhaustive, not
# curated-down" approach lucide_ids.txt's own header documents for that
# source): every one of the 670 `-fill.svg` files under icons/ in this
# pinned version (the plain, non-suffixed *.svg outline variants alongside
# them are NOT this project's concern). One of the 670, circle-fill.svg,
# is a bare `<circle>` element rather than a `<path>` at all -- included
# here anyway (a full-set import, per the brief, doesn't hand-trim around a
# single known-unmergeable id) and left for fetch_bootstrap.py's normal
# skip+log path (common.extract_fill_path rejects any non-<path> drawable
# element) to report at fetch time, the same "don't silently mangle, skip
# and log" contract every other failure mode in this pipeline follows.
#
# Format: same convention as material_ids.txt/phosphor_ids.txt/
# lucide_ids.txt/tabler_ids.txt/remix_ids.txt -- '#'-prefixed lines are
# comments, a '# category: <bucket>' line sets the manifest `category` for
# subsequent ids until the next such marker. One bare Bootstrap icon id per
# line (the filename under icons/, without the `-fill.svg` suffix; native
# hyphens, e.g. "lightning-charge" -- fetch_bootstrap.py converts to
# underscores for the manifest id, "bootstrap_lightning_charge").
#
# Category mapping rule: Bootstrap Icons ships no per-icon category/tag
# metadata at all (unlike Tabler's icons.json) -- categorized via
# common.classify_by_keyword(), the same shared priority-ordered
# electrical/network/av/arrow/safety token-set walk fetch_fluent.py also
# uses directly and fetch_tabler.py uses as ITS fallback, applied to each
# icon's own id tokens (hyphen-split). A small hand-picked override list on
# top (the same escape hatch lucide_ids.txt's own header documents
# needing): "cloud" is a real network/cloud-storage signal (cloud,
# cloud-arrow-down, cloud-check, cloud-download, cloud-upload, ...) but
# Bootstrap also ships a full cloud-<weather> family (cloud-rain,
# cloud-snow, cloud-fog, cloud-haze, cloud-hail, cloud-sleet,
# cloud-drizzle, cloud-lightning, cloud-lightning-rain, cloud-moon,
# cloud-sun) that the bare "cloud" token can't distinguish from actual
# cloud-computing icons -- those 14 weather-compound ids are hand-forced to
# misc rather than landing network (or, for the two cloud-lightning ids,
# electrical) by coincidence.
#
# Category distribution at generation time: electrical 4, network 17,
# av 33, arrow 33, safety 19, misc 564.
